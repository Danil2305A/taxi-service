# taxi-service
## Backend микросервисного приложения для заказа такси
Сервис моделирует упрощённую платформу заказа такси. Пассажир создаёт поездку, система ищет
подходящих водителей, назначает поездку, обновляет статусы и формирует историю. В фоне работает
сервис, который обрабатывает очередь заказов и рассылает уведомления.
## Как запустить
1. Создайте на основе .env.example файл .env, пропишите параметры подключения к БД, JWT-секрет
2. Соберите и запустите контейнеры
```
docker compose up -d
```
